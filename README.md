Leonida Trophy Guide — a complete, offline trophy guide for Grand Theft Auto VI on PS5: all 55 trophies (1 platinum, 2 gold, 6 silver, 46 bronze) with a guide written for each one, a four-stage platinum roadmap, and a checklist tracker that saves your progress in the browser. Search, filter by kind and grade, hide story spoilers until you earn them, and export or import your progress. No accounts, no network, no official artwork.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
